# 续页 Xuye 官网

产品宣传、使用帮助与中英文隐私政策，参考极拼官网的叙述和交互方式，使用续页的青色折页品牌。

- 页面：`index.html`、`support.html`、`privacy.html`。
- 原生 HTML/CSS/JavaScript，无依赖安装和构建步骤。
- 图标来自正式 App；展示图来自当前项目的 0.1.5 模拟器真实界面，保留生成示例标识。
- 官网使用“续页 Xuye”；当前提交的 App / TestFlight 英文名称仍为 Longlet，本次未修改安装包名称。
- 未制作新的公开 TestFlight 邀请，下载区按实际审核状态显示。
- 网站不接收屏幕或相册数据，没有上传、账号、广告及自行配置的分析服务。网站托管请求与 App 本机处理的区别已在隐私页说明。

网站通过本仓库的 GitHub Pages 发布，配置与极拼官网一致：`codex/app-store-pages` 分支根目录，`legacy` Pages 构建。主分支 `website/` 保存源文件，发布分支只包含这些静态页面与素材，不添加应用构建 CI。

本地预览可用 `python3 -m http.server --directory website 4173`，或使用其他静态服务器。无需启动 App 模拟器。
