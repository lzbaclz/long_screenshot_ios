## 必须证明的行为

1. 固定栏与正文同色、胶囊只在后帧出现时，向上扩展不会把状态栏和导航栏带入正文条带；胶囊只在首帧出现的反方向也覆盖。
2. 不能只验证长图高度。原生 PNG 须与独立的“上端视口原始固定栏 + 连续正文 + 下端视口原始输入栏”像素真值相符；真实手势测试另检查正文条带来源与固定图标出现次数。
3. 固定结构带约束整页平移路径，壁纸前景路径豁免。候选的实际来源必须明确，不能仅凭调用参数为空推断来源。
4. 不改变原移动证据规则或为修复降低歧义门槛；朋友圈完整自动区域、壁纸聊天、短中文和键盘场景不能退步。
5. 匹配区域与保护带诊断以原始画面像素记录；未记录或不适用与数值 0 区分。旧会话无需迁移，用户手动范围仍保留其原有语义。
