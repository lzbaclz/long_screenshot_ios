## 失败、缺测与变更处理

- 部分成果、起点缺失、主动报错、导出失败均不计完整成功。未执行填 NA；报告覆盖不足，不把缺测并入成功分母。
- 全部已执行失败保留原始记录。修复后的重测另建 run ID，关联原失败，不覆盖或删除旧值。
- 手工裁剪、缩小导出、观察员帮助等作为实际条件记录，不能未经预先规定直接等同自动完整成功。
- 不把未确认起点的连续片段当作预定首尾均捕捉；有起点告警但实际完整，可按画面核对结果记录，并单列告警率。
- G1、G2、G3 都需要明确评审记录。门槛、平台或样本口径变更需写明原因与新版本，不追溯修改已经失败的判定。
