# 续页 / Longlet 真实设备验证规程

状态：执行规程，所有真实测试结果另填。依据 [立项计划](../project-plan.md)；与 [门槛证据表](gates-and-evidence.md) 配套。测试只使用自建或获准的内容，不读取私人聊天作为样本。

## 证据类别与前置条件

每次记录必须标为以下之一：`physical-target-app`（真实设备与目标 App）、`physical-fixture-app`（真实设备与独立自建测试 App）、`simulator-ui`、`synthetic-algorithm`。只有前两类能证明其对应的真机行为；自建聊天页面不能证明微信兼容性，模拟器演示不能证明跨应用采集。

准备签名匹配的主应用与扩展、足够存储、合法测试内容、独立计时方式。记录实际 iPhone 型号、iOS 完整版本、构建号、App Group、目标 App 版本和内容版本。保存开始与结束的可核对行号、图案或段落标记，关闭真实私人通知。不得为了录证据同时启动另一项占用系统屏幕捕捉的录屏；可使用外部摄像或观察员时间记录。

计划需要至少 4 组真实设备系统组合，包含低内存设备及 iOS 18、26、27。无法取得的组合填“未覆盖”。iOS 27 SDK 或新后端尚未通过验证时，不把旧 SDK 编译成功写成新后端通过。

## 单次标准操作

1. 冻结用例内容、起止标记、目标长度、浅/深色、上下忽略比例、停止模式及目标 App 版本。
2. 清理或标明历史测试作品；记录剩余存储、温度状态、后台条件与网络条件。无需删除真实用户数据。
3. 让目标内容停在指定起点。记录任务计时起点，不提前滚动到中段。
4. 按指定入口启动：控制中心长按“屏幕录制”选择续页，或从续页内系统选择器开始后切到目标 App。保持麦克风关闭，记录系统授权与捕捉指示。
5. 关闭系统面板，待起点画面稳定后平稳向下滑动；每次保留明显重叠。需要回滑的用例按预定轨迹执行。
6. 到结束标记后按用例要求停止，返回续页。记录系统停止提示、状态、起点变化提示和可操作预览时间。
7. 按 100% 比例核对首尾、顺序、所有接缝及关键图片，不能只看缩略图或 OCR 一致。
8. 导出所指定格式。记录是否触发大图选择、明确选择的输出尺寸、写入完成时间及文件是否可打开。
9. 依据下方判定分别记录“完整成功、已提示的部分结果、失败、未提示内容错误”。不能因为生成了图片就记成功。

## 必测矩阵

| 编号 | 场景与动作 | 检查重点 |
| --- | --- | --- |
| ENTRY-01 | 已在目标 App，控制中心启动，5 屏手动停止 | 起点段落保留，系统面板没有被当正文拼入 |
| ENTRY-02 | 应用内启动后切至目标 App，5 屏手动停止 | 候选起点替换过程，结果提示，最终起点完整性 |
| START-01 | 停在同一屏不滚动，随后停止 | 不报告长图完整成功，明确说明未检测到可衔接滚动 |
| START-02 | 第一段故意快滑超过可匹配重叠，再慢滑 | 起点变化告警可见；遗漏初始段落不能计完整成功 |
| BAR-00 | 上下忽略比例均为 0，分别测试清晰固定边界及含不明确留白的边界 | 自动识别只裁去有把握的固定区域；无法确定时停止并引导手动设置，不静默裁掉正文 |
| BAR-01 | 固定顶栏与底栏，忽略比例分别为 0 和人工确认值 | 正文未被裁掉、固定栏不反复拼入；记录有效视口高度 |
| BAR-02 | 透明顶栏/聊天背景/深色模式 | 重影、重复、模糊、是否明确拒绝不可靠匹配 |
| FLOW-01 | 5、10、20 屏稳定文字与静态图片 | 首尾、连续性、20 屏边界，确认“屏”按裁除固定栏后的有效视口计算 |
| FLOW-02 | 前进、短回滑、再超过原最远位置 | 已见部分不重复，新尾部只追加一次 |
| FLOW-03 | 长距离回滑、横向变化或无重叠跳转 | 不猜造缺口，已确认部分仍可访问 |
| IDLE-01 | 首次滚动后分别静止 5/10 秒，另测等待图片加载 | 自动结束时间、系统提示、误提前结束；未滚动阶段不会因静止结束 |
| LIMIT-01 | 选择 5/10/20 屏上限并继续滚动 | 到上限停止、有说明、连续片段可用；付费不突破上限 |
| LIMIT-02 | 手动模式超过 120 秒 | 时长上限触发，保存已有内容，界面没有永久挂起 |
| SIZE-01 | 高分辨率 20 屏超过 3200 万像素或单边 32000 像素 | 默认拒绝超限单图；仅在明确选择后缩小，原始分块保留 |
| PHOTO-01 | 首次保存拒绝“添加照片”，重试，再去设置恢复权限 | 不读取图库、拒绝后有反馈、失败不扣次数，恢复后可保存 |
| SHARE-01 | 分享取消、保存成功、重复导出同一作品 | 取消不扣次数，首次成功才计数，同作品只计一次 |
| EDIT-01 | 裁剪首尾、遮挡敏感测试块、修剪重复接缝 | 遮挡位置正确；缩小 PNG 边缘无半透明泄漏；JPEG 检查实际解码效果 |
| DATA-01 | 遮挡后导出、重新编辑、删除作品 | 原图仍可编辑的提示准确；删除本机源图不影响外部副本 |
| INT-01 | 锁屏、系统暂停、电话等受控中断 | 明确终态；已有分块可恢复，不要求私人通话内容 |
| INT-02 | 开发测试中终止扩展进程，等恢复阈值后打开宿主 | 文件锁随进程结束释放、最新完整清单保留、没有覆盖新分块 |
| INT-03 | 捕捉时打开宿主并尝试编辑/删除，模拟忙碌心跳延迟 | 活跃写入租约阻止恢复、编辑和删除，不把忙碌当死亡 |
| FAIL-01 | 有界低存储测试，缺失/损坏测试分块 | 不覆盖或自动删除原件；明确失败，恢复入口与实际能力一致 |
| ORIENT-01 | 起点前、已开始拼接后分别旋转 | 未开始可重新定位；已开始则说明尺寸/方向变化并保留部分 |
| LANG-01 | 简体中文、英文分别执行启动、告警、保存拒绝 | 关键操作与失败说明可理解；实际系统弹窗语言另记 |

破坏性故障注入仅针对隔离的测试作品；不压满整台私人设备、不删除业务数据。缺少注入条件时记“未执行”，不能用单元测试结果填真机结果栏。

## 完整性与性能口径

完整成功必须覆盖预定起止标记，顺序正确，无重复正文、漏行、可见重影，且最终图片可导出。部分结果即使保存正确，也不计完整成功。出现“完成”且没有相关警告的漏行、错序或重复，另记静默内容错误并作为阻断问题。

任务总耗时：目标内容已准备好 → 最终保存完成，含授权、应用切换、检查及重试。预览耗时：宿主收到结束状态 → 首个可操作预览。导出耗时：点击保存 → 系统报告写入完成；权限弹窗交互分别保留总值与拆分值，不删除较慢样本。每次记录原图/输出尺寸及是否缩小，不能用缩小图耗时证明原尺寸导出性能。

使用 Instruments 或可复核的设备指标记录扩展/宿主峰值内存、CPU、处理间隔和异常终止。Mac 上算法耗时不是 iPhone 指标。P95 使用冻结样本的第 `ceil(0.95 × n)` 个排序值，并同时给样本数、失败数和原始列表。

真实测试内容与参与者联系方式分开保管；仓库中只保存脱敏证据和代号。构建、目标 App、关键设置变化时重新标注批次，不能混合后挑选较好成绩。
