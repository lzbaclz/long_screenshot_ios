## 本次变化

1. 从当前位置往页面上方或下方都能扩展长图，往返已覆盖区域不重复，输出保持自然阅读顺序。
2. 测试版每周免费导出 50 个新作品，按设备本地 ISO 周更新；保留原成功记录，失败、取消及同一作品重复导出不扣次数。不依赖沙盒收据来决定额度。
3. 对白底稀疏文字增加有效细节证据，避免空白面积稀释正确匹配；自动区域用于内部接缝，原始首尾各保留一次。短暂不匹配允许恢复，持续至少 8 秒且至少 6 次拒绝才结束已有长图，仍不跨未知缺口拼接。
4. 候选首屏在共享存储中原子发布；首次提交、替换候选失败或采集进程结束后，可恢复明确标注的单屏。空记录显示失败原因，不再把 0 × 0 说成“部分内容已保留”。
5. 增加仅保存在本机的采集阶段、停止原因、帧计数与处理耗时，方便下一轮真机定位。它们不包含识别文字或来源 App 名称，不自动上传。
