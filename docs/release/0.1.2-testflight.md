# 续页 / Longlet 0.1.2（3）聊天向上起步修复

日期：2026-09-14。当前状态：本地逻辑验收通过，准备手动分发；上传及组内状态将在核验后更新。

## 反馈与已复现问题

用户反馈 0.1.1（2）向下浏览可正常截图，但进入聊天记录后直接向上翻，结束时仅有单屏。用户没有先向下浏览，也未提供具体诊断阶段；不能将这次问题直接归因为系统中断。

本轮复现两类会阻止首接缝的限制：

- 输入栏、键盘或底部大块留白遮住了边缘运动特征。即使核心已识别正确负向位移，自动区域候选仍为空。主 agent 的真实 UIKit 键盘场景在修改前明确失败，修改后原输入和原像素期望均通过。
- 1179 像素宽、36 像素字号的单／双字中文气泡，横缩为 144 像素后，细节横跨度可能只有 16 像素；旧门槛却要求 24。独立穷举找到唯一精确位移，但旧实现仍全部拒绝。左右两侧和交替短消息已补入回归。

## 修复

1. 在真实信息区间分配细节采样预算，保留多结构、多行、纵向分布及原误差／歧义门槛。窄文字和头像不再因占屏比例小而直接拒绝。加载矩形边缘、细滚动条和周期内容仍有拒绝验证。
2. 自动起步可使用经过重放核验的内部运动区域，并增加避开键盘的非对称窗口；不再要求上下两端都出现文字。首尾原始内容仍各保留一次。
3. 采样行使用镜像配对，减小取整网格造成的方向布局差异。自动屏数预算与内部窗口解耦，最终高度仍不超过完整视口乘设置屏数。

每周 50 次额度、成功记录、权限和发布方式延续既有政策；本轮没有运行云端 CI。
