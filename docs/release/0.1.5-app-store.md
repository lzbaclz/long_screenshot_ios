模拟器原始 PNG 带 Alpha 通道，不符合 [Apple 截图规格](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications)。保留本机原 PNG，使用 `sips` 按原尺寸转成质量 95 的 JPEG；重新核对四张尺寸与 `hasAlpha: no` 后替换首次上传素材。此转换不改绘界面或示例内容。原 PNG 不作为最终上传素材。
