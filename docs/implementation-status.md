## 环境基线

- Xcode 26.3，iPhoneOS SDK 26.2；按命令设置 `DEVELOPER_DIR`，不修改系统全局配置。
- iOS 26.3 模拟器可用，单独创建 `LongScreenshot-Dev`，不复用其他项目正在运行的模拟器。
- 已识别配对 iPhone，签名与应用组可用性仍需实际构建确认。
- 尚无本机 iOS 27 SDK，也未确认 iOS 18 真机。ScreenCaptureKit iOS 27 路线保留为条件启用项，不能标为已验证。
